# Frequently Asked Questions

## Does Row-Bot send my data anywhere?

Your chats, memories, documents, workflows and settings stay on your computer. Row-Bot sends something out only for what you use, such as a hosted model, a web search, an app or a channel. Apart from that, it sends a daily install count (a random ID, the version and the system), which you can turn off in one click. [Privacy And Safety](/docs/privacy-safety/) has a table of every connection.

## Can I use Row-Bot without the internet?

Yes, with a local model in Ollama. Chats, memory, documents and workflows then work offline. Anything that needs the internet, such as web search or a hosted model, tells you when it can't reach it.

## What does it cost?

Row-Bot is free and open source. You pay only your model provider: nothing for a local model; your existing ChatGPT, Claude or Grok plan; or per use with an API key. The ring beside **Send** shows how much of the model's context a chat fills. To see usage across chats, ask "How many tokens did I use this week?".

## Which model should I use?

Use the most capable one you have. On first run, Row-Bot tags up to three local models **Recommended**, larger ones that use tools first. Workflows, pages and code work best on a model that uses tools well. See [Model Picker](/docs/chat/model-picker).

## Will Row-Bot do things without asking me?

Only at the level you choose. **Ask** asks before anything that makes changes. **Auto** has a reviewer approve what clearly matches your request, and asks you about the rest. **Hands-off** runs everything and records it. **Block** runs nothing that makes changes. **Always ask me** on a workflow step or an app keeps it asking you whatever the level, and saving memory from an incognito chat always asks. See [Approvals](/docs/chat/tools-approvals-and-terminal#approvals).

## Can I use it from my phone?

Yes. Connect your phone in **Settings › Devices & remote access**. It gets the same chats, approvals, pages and the Browser pane. See [Phone And Native Desktop](/docs/mobile-native/).

## What can Row-Bot do?

Ask it: "What can you do?". It answers from its own list of features and what you have set up. These docs cover each one, and [What's New In 5.3](/docs/getting-started/whats-new) lists the latest.

## How do I keep a chat out of memory?

Make it [incognito](/docs/chat/#incognito-chats): **New chat ▾ › New incognito chat**, or the chat's **⋯ › Incognito**.

## How do I update, back up or move Row-Bot?

Row-Bot updates itself in the background and asks you to restart. Back up and restore in **Settings › Data**. See [Updates](/docs/operations/updates) and [Operations, Data, And Recovery](/docs/operations/).

## Something isn't working. Where do I start?

Check the sidebar's attention indicator, Overview's **Needs you** and [Monitor](/docs/monitor/), which offer one-click fixes. Then see [Troubleshooting](/docs/troubleshooting/).
